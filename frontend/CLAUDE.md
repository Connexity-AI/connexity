# Frontend conventions

Applies to all code in `frontend/`.

## Checks

```bash
cd frontend
pnpm lint                # ESLint
pnpm turbo check-types   # TypeScript (regenerates Next route types, then tsc --noEmit)
```

## Testing

Dmytro tests screens himself. Run lint, types and the build; do not start a browser
preview, take screenshots or click through the UI. In the plan's Outcome, list the pages
he should open and what should be true on each.

## What the UI is for

The assistant does all of the work. Next to it, the web app's value is the quick
glance: a dashboard where a person sees in seconds how the fleet is doing, what was found
and what is moving (Decided 2026-11-09). Build every screen from the Connexity Design
System in Claude; see "UI: the design comes first" in the lifecycle guide.

- **Every number shows its base:** how many agents, how many calls, over what period.
- **Give before asking:** a screen opens with findings and progress. What needs the
  person (approvals, questions) is counted, never first.
- **The sidebar** is Home, Incidents, Action items, Agents, Calls, Roadmap, Issues and
  Settings (Decided 2026-11-12). The Connexity logo stays at the top; there is no
  white-labelling. The workspace picker, Account, Theme and Sign out live in the menu
  that opens from the person's name at the bottom.
- **Only what works is on screen.** Pages and tabs appear when their feature is built;
  designs show more than a build does (`CLAUDE.md` rule 14).
- **Calls can be browsed and found** (Decided 2026-11-11): newest first, search by phone
  number or call ID, filters for agent, result, category, period and source. Callers
  show as the last four digits.
- **The deepest view is a single call:** its recording and transcript, with tool calls
  inline (one collapsed line each, expanding to arguments and result) and findings at
  their moment (Decided 2026-11-12).
- **Small charts always show their time scale:** start and end labels and the peak with
  its unit.
- **No small metadata lines** ("You, today · used twice this month"): records live in
  logs and the audit log, not on every row.

Do not add:

- trace explorers or drill-downs below a single call; query builders or filters beyond
  the ones above (Proposed)
- forms for what the assistant can set through MCP (connections, agents); keep forms
  and controls only where a person must act themselves, such as signing in, their own
  account, and the decisions only a person confirms (check settings, gate settings,
  archiving, closing an incident) (Proposed)
- a chat box, or anything that replies to the user
- editors for the agent's prompts, tools or workflows, or anything that deploys or
  writes to a provider. Connexity never changes the agent itself.
- AI that generates content inside the product (an internal assistant, test case
  generation). That is the external assistant's work.
- anything removed during the rebuild, without asking first

## Architecture

- **Never edit `apps/web/src/client/`.** It is generated by Hey API and overwritten.
  Types come from there; do not hand-write types the codegen should produce.
- **Auth** is an HttpOnly cookie JWT (`auth_cookie`). Server code uses `serverFetch`.
  Client code goes through `/api/client-proxy/[...path]`, because the browser cannot
  read the cookie. Do not bypass the proxy or add another auth mechanism.
- **Server Components by default.** Add `'use client'` only for interactivity.
- **Wrap async server components** in `<ErrorBoundarySuspense fallback={<Skeleton />}>`.
- **Data fetching** follows the `tanstack-streaming` skill.
- **Dialogs** open through the custom event system in `src/constants/events.ts`, not
  lifted state.
- **Server actions** in `src/actions/` for submissions, following the `ApiResult`
  pattern (strip the `Response` object before returning).
- **Environment variables** are validated with Zod (`@next-public-env`). The repo root
  `.env` is the only env file.

## Style

- **TypeScript strict.** No `any`; use `unknown` and narrow, or the generated types.
- **Functional components, named exports**, props destructured in the signature.
- **Colocate** component-specific types, constants and helpers.
- **No barrel files.** Import from the source file.
- **Zod schemas** in `src/schemas/` with React Hook Form and `zodResolver`.
- **Tailwind v4** with `cn()` for conditional classes.
- **ShadcnUI** (new-york) from `packages/ui/`. Check for an existing component first.
- **`pnpm`** only.
